================================================================================
TROUBLESHOOTING
================================================================================

Problem: "relation schedules does not exist"
→ You haven't applied the database migration yet (see step 1 above)

Problem: My Schedules menu item doesn't appear
→ Clear cache: npx expo start --clear --web

Problem: "Not handled by any navigator" error
→ Already fixed - if you see this, ensure frontend restarted

Problem: Can't connect to database
→ Check PostgreSQL is running
→ Check password: postgres@123
→ Check database name: education_erp

Problem: Backend not responding
→ Check unified_backend is running on port 5000
→ Check .env file has correct DATABASE_URL

Problem: Red dots not showing
→ Make sure schedules have status='pending'
→ Completed schedules don't show red dots
